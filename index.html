    Pengaturan Firebase

    UID kamu:

    1. Firebase Console > Authentication > Settings > Authorized domains: tambahkan domain tempat file ini dibuka. Login Google tidak jalan jika file dibuka langsung dari penyimpanan perangkat.
    2. Wajib sebelum mengubah diamond atau koin: salin rules di bawah, lalu Firestore Database > Rules > Publish. Tanpa ini, pemain yang profilnya sudah berisi dm atau co gagal menyimpan nama, kemenangan, dan rank.
    3. Diamond disimpan di field dm, koin di co, pada profiles/{uid}. Pemain tidak bisa mengubahnya sendiri. Game harus membaca dua field ini agar angkanya tampil di menu.
